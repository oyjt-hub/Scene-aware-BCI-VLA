步骤04：评价字段表与计算口径
版本V2；日期2026-10-15；本文是字段设计，不是已实现的protocols.py或评价器。
类型：text / enum / bool / number / timestamp / object / list；未测或不可得用null并附missing_reason；0只用于实际测得零。
存储权限：PUBLIC仅在线运行必要内容；PRIVATE仅调度/评价；OUTCOME独立结果标注；DERIVED冻结输出后离线计算。

一、在线可见PUBLIC（采用允许字段列表）
schema_version:text；session_id/event_id/interaction_id:text伪名；mode:enum；response_to:text|null。
task_id/task_revision、scene_revision、mapping_id:text；channel_profile_id:text|null为允许使用的校准模型标识，不是真模式标签。
prompt_symbol:text|null只对已发CHANNEL_PROBE；prompt_source/display_ack为提示来源，不能证明遵从。
observation:object，包含公开场景/候选/用户解码输出；raw_scores、score_kind、calibration_id、quality、signal_status按步骤05/06定义。
window_id、source_recording_alias、capture_start/end、host_id、clock_uncertainty_ms、sample_rate_hz等为来源/计时元数据。
published_history仅含当时合法可见记录。不得包含private_goal、true_channel、factor_cell、future_schedule、evaluation_seed或独立研究确认。
正式字段以步骤05实现为准，本表不授权把私有分配标签挂在metadata里传入模型。

二、私有调度/真值PRIVATE
study_id/plan_version/plan_hash；assigned_method、paired_condition_id；participant_alias/session_group/scene_group/recording_group仅评价分组使用。
factor_cell_intended:C00/C10/C01/C11；factor_cell_observed:同前或unknown/not_exposed；goal_changed与channel_changed是两个bool|null。
evidence_level:L1/L2/L3/L4/L5；task_card_id/revision、prescribed_goal、goal_source、cue_sent/presented、comprehension_source/time。
goal_valid_from/to_interval、goal_truth_validity:known/interval/ambiguous/unknown，goal_truth_note明确指令目标与内部意图区别。
channel_intervention_id/kind、injection_site、applies_to_modes、mode_before/after、intended/actual_change_interval、injection_seed。
channel_truth_source:simulation/digital_transform/independent_calibration/controlled_condition/unknown。
channel_truth_scope:injected_component/effective_response_estimate等；calibration_uncertainty、mode_transfer_validity及adherence_annotation。
stress_tags:list；assigned_schedule与actual_exposure分开。独立理解/遵从标注不得从算法输出复制。
change_time_known:bool；不存在精确变点时actual_change_interval可null，相关延迟不可计算。

三、独立终态与执行事件OUTCOME
attempt_id、dispatch_time、contract_id/revision、commanded_intent、completion/termination_time、termination_reason。
终止原因至少含success_predicate_met/timeout/user_cancel/abstain/system_error/invalid_signal/unsupported_task/unknown。
physical_or_virtual:enum；endpoint_predicate_version、endpoint_evidence_ref、judges、blinding_status、disagreement/adjudication。
goal_at_dispatch_ref、temporal_ambiguity、intent_match:true/false/null；endpoint_success:true/false/null。
faithful_completion:true/false/null＝独立目标匹配且该目标终态达标；不以API返回success、提议ready或LLM评分生成此值。
执行中改目标单独记录contract_expired/stop_requested/recovery等，不追溯改写此前合法启动为错误。
所有分阶段时间保存起止区间；派生计时前标明时钟域/校正。重叠阶段不得重复累加。

四、episode主指标DERIVED（统一N为全部已开始的分配episode）
N_all_started：按预锁trial_start规则入组总数，含无冲突、失败、超时、取消、弃权、日志部分缺失。
S：已知独立真值且忠实完成；F：已知未忠实完成；U：信息不足无法判断；N=S+F+U。
faithful_completion_rate_known=S/(S+F)，仅作已知真值条件性结果；若分母0则null。
faithful_completion_lower=S/N；upper=(S+U)/N，并报U/N；防止剔除未知后虚增完成率。
cancel/abstain/timeout等已知未完成计F，除非本来因目标/终态丢失无法判定；缺失分类按冻结规则，不因方法表现改变。
wrong_start_episode：有任一启动与当时有效独立目标不符；无启动为false；有启动但所有相关判定不清为unknown，不能默认false。
若某episode已存在确定错误启动，则即使还有未知启动也为true；否则有未知启动时整体为unknown。
W：确定错误启动episode数；U_w：不能判断是否错误的episode数。错误启动下/上界=W/N与(W+U_w)/N，并报启动覆盖率。
另报每次启动错误数/全部启动数的条件结果及其未知比例；不能代替全episode指标。
start_coverage：有下发的episode数/N；abstention、timeout、unsupported与unresolved分别计数/占比，多标签与互斥终止原因区别。
total_elapsed_observed_s：trial_start至终止的已观测时间；无法算则null并附原因。超时保留共同上限及实际终止时间。
user_busy_s：阅读/操作/刺激注意/确认/重试的区间并集；probe_busy_s为其中probe区间并集；阶段耗时可交叠，不直接相加。
单独报告全体已观测时长、各终止类型及缺失率。未完成不能当作更快完成；可另报固定时限内完成比例/删失时间分析，细节正式前锁定。
仅成功试次平均耗时最多作次要描述，必须同时给总体失败/超时和删失情况。
按随机分配四格及证据层级分别报告；actual_exposure分层补充，不将未暴露者改分配。

五、误诊机制DERIVED
new_goal_rejected_to_old：独立目标确已变且可判时，系统仍选择/保留旧目标的事件或episode；定义保持多久及观察窗待pilot锁定。
channel_change_accepted_as_new_goal：独立目标未变而通道干预/可测变化存在，系统启动不符目标；不能仅凭算法“原因分类”计真误诊。
mode_misupdate：独立可判通道条件下错误模式后验决策/配置切换；parameter_misupdate仅真有参数更新且可判时适用。
无在线参数更新时parameter_misupdate_rate=null且missing_reason=not_applicable，不写0暗示已经证明无错。
goal_detection_delay/channel_detection_delay：检测时间减可知变化时间；区间真值给延迟区间，检测前置为误报/提前报警，不静默截成0。
未检出分别给miss/右删失及观察窗；无可靠变点L3不填精确delay。
false_alarm_count及false_alarm_per_stable_time：稳定时长独立可知才计算；不按方法自己宣布稳定定义分母。
probe_count/probe_busy_s、task_query_count、confirm_count、retry_count、wrong_update_count、unresolved_duration及低变化率开销。
后验校准/Brier/log score仅在独立状态真值及同状态空间可用时计算，零概率处理规则正式前冻结；未知标签不能由本方法后验补齐。

六、缺失、泄漏与分析单位
每个null附missing_reason：not_collected/not_applicable/truth_ambiguous/log_missing/clock_unsynced/not_exposed等。
PRIVATE/OUTCOME连接只在冻结方法输出后执行；原始数据摘要或公开event的未知metadata不得携带私有真值。
同一用户/会话/物理场景/录制前缀不能按行当独立样本。分析单位和分组与研究泛化主张一起锁定。
空白模板所有结果留null，不把计划事件、设计四格或样例当真实episode数。
